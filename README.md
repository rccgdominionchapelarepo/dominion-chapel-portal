# RCCG Dominion Chapel - Web Portal & Administration System

A comprehensive, responsive web application built to serve the congregation of RCCG Dominion Chapel (LP 21 HQ Annex, Arepo). This platform provides a dynamic public-facing website and a secure backend administration portal for managing church resources.

## ✨ Key Features

- **Sermon & Media Management:** A dual-purpose publishing system for sermons and church news, featuring speaker images, presentation slide downloads, and dynamic quote arrays.
- **Dominion Magazine Portal:** A dedicated PDF publication system allowing administrators to upload magazine covers and heavy PDFs, rendered in a beautiful public download gallery.
- **Bulletproof Responsive Design:** Custom dark-navy (`#050A15`) and gold (`#D4AF37`) aesthetic with a robust, pure-click mobile navigation system that overrides iOS/Android hover bugs.
- **Secure Administration Dashboard:** Role-based access for admins to perform CRUD operations on church media, magazines, and incoming inquiries.
- **Contact & Inquiry System:** Upgraded contact forms supporting anonymous submissions, with backend admin filtering (by subject and read status).
- **Direct Giving Portal:** Seamless layout for church offerings, tithes, and project accounts with clear, accessible bank details.

## 🛠️ Tech Stack

- **Backend:** Laravel (PHP)
- **Frontend:** Blade Templating, Alpine.js, Vanilla JavaScript
- **Styling:** Custom CSS & Tailwind CSS
- **Database:** MySQL

## 🚀 Installation & Local Setup

Follow these steps to get the project running on your local machine.

### 1. Prerequisites

Ensure you have the following installed on your system:

- [PHP](https://www.php.net/) (v8.1 or higher)
- [Composer](https://getcomposer.org/)
- [Node.js & npm](https://nodejs.org/)
- [MySQL](https://www.mysql.com/)

### 2. Clone the Repository

```bash
git clone [https://github.com/YOUR-USERNAME/dominion-chapel-portal.git](https://github.com/YOUR-USERNAME/dominion-chapel-portal.git)
cd dominion-chapel-portal
```
